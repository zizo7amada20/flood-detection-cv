# Flood Detection - Computer Vision Pipeline

موديل لاكتشاف مناطق الفيضان من صور الأقمار الصناعية (SAR + Optical)
باستخدام Sentinel-1 و Sentinel-2.

## التشغيل
1. pip install -r requirements.txt
2. حمّل الداتا من رابط ImpactMesh-Flood
3. شغّل main.py

## هيكل المشروع
- preprocessing/ - تنظيف صور SAR وOptical
- models/ - كود الموديل
- main.py - نقطة البداية
